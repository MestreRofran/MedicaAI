# Privacidade e cuidados com os dados — MedicaAI

O MedicaAI organiza informações relacionadas à saúde, que podem ser sensíveis. Esta versão foi pensada para uso pessoal e oferece os seguintes recursos e limites:

- Não é necessário criar conta para utilizar as funções principais.
- Os registros são salvos no armazenamento local do navegador; **esse conteúdo local não é criptografado**.
- Em caso de limpeza dos dados do navegador, troca de aparelho ou desinstalação, os dados podem ser perdidos se não houver backup.
- É possível exportar ou importar arquivos JSON. Esses arquivos não são criptografados: guarde-os em local seguro.
- Opcionalmente, você pode conectar sua conta e enviar um **backup criptografado** para a nuvem. A criptografia é feita no dispositivo usando AES-GCM e uma senha de proteção fornecida por você. Essa senha não é armazenada pelo MedicaAI.
- O conteúdo é descriptografado localmente ao recuperar um backup, mediante senha correta.
- O envio é manual. A opção de armazenamento escolhida não significa que todos os dados estejam sendo sincronizados automaticamente.
- O aplicativo usa os recursos de autenticação e banco de dados do serviço de nuvem configurado. Consulte também as políticas da plataforma que hospeda o aplicativo e do provedor de nuvem.
- Esta versão não cria contas clínicas compartilhadas, não substitui prontuários e não oferece um sistema de permissão entre familiares.

**Atenção:** um aplicativo publicado abertamente e desenvolvido para uso pessoal não se torna automaticamente adequado para tratamento profissional de dados clínicos. Antes de disponibilizá-lo para terceiros, é importante revisar aspectos de segurança, privacidade e exigências legais, incluindo a LGPD.

O MedicaAI não oferece orientação médica. Em caso de dúvidas, siga a prescrição e consulte um profissional de saúde.
